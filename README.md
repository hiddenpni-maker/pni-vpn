<a name="فارسی"></a>

🇮🇷 معرفی کامل پروژه (فارسی)

pnifox یک کلاینت نیتیو و یکپارچه برای اندروید و ویندوز (Kotlin + Jetpack Compose Material 3) است که مجموعه‌ای کامل از موتورهای رفع فیلتر، بهینه‌ساز گیمینگ، تونل DNS و اسکنر چندشبکه‌ای IP تمیز را در یک رابط کاربری جمع‌وجور، سریع و دوزبانه در اختیار شما قرار می‌دهد.

✨ ویژگی‌ها و امکانات کلیدی

رفع فیلتر یکپارچه (پیش‌فرض آماده بدون نیاز به سرور):

اتصال پیش‌فرض روی MASQUE (HTTP/2) + چین سایفون برای بیشترین پایداری و عبور از تحریم و فیلترینگ.

ذخیره هوشمند آخرین IP اسکن‌شده (Endpoint Cache) برای اتصال فوری در دفعات بعدی بدون اسکن تکراری.

پشتیبانی از فرانتینگ CDN (Akamai و سایر CDNها)، WireGuard روی MASQUE، رله MHR و شبکه Tor با پل‌های آماده.

گزارش زنده و قابل‌فهم مراحل اتصال بر اساس لاگ هسته، نمایش آی‌پی اتصال، تغییرات اعمال‌شده روی شبکه، سرعت لحظه‌ای دانلود/آپلود و تست پینگ واقعی.

بخش گیمینگ و بهینه‌ساز DNS Spy:

تشخیص جعل DNS (DNS Hijacking Guard): بررسی هم‌زمان سرورهای DNS گیمینگ و ضدتحریم (رادار، الکترو، ۴۰۳، شکن، بگذر، کلودفلر، گوگل، ادگارد) و شناسایی سرورهای مسموم (10.10.34.x).

استفاده از DNS پرایوت و ضدتحریم بدون ثبت IP و بدون افزایش پینگ بازی.

کاتالوگ تست پینگ زنده بازی‌ها: سنجش تاخیر TLS و پکت‌لاس سرورهای بازی (COD Mobile، Steam، Valorant، PUBG، Fortnite، EA/FC).

حالت ضدDPI محلی (بدون سرور) با تکه‌تکه‌سازی بسته‌های TLS، پشتیبانی از کانفیگ‌های پنل‌های Cloud و سرورهای گیمینگ شخصی، و گزینه نادیده گرفتن محدودیت باتری در اندروید.

پشتیبانی کامل از سرورها و پروتکل‌های مدرن:

پشتیبانی از VLESS، VMess، Trojan، Shadowsocks، WireGuard، Reality، XHTTP / SplitHTTP، WS، gRPC، HTTPUpgrade، Hysteria2 (با obfs)، TUIC v5 و AnyTLS.

تنظیمات کامل TLS Fragment، UDP Noise، زنجیره پروکسی (Chain Proxy)، موتور محلی SNI Spoof (127.0.0.1:40443) و ویزارد ساخت Worker کلودفلر داخل برنامه.

تونل DNS و تغییر DNS پیشرفته:

لیست یکپارچه پروتکل‌های UDP، SuperDNS، FastDNS، PDoQ، DoH و DoT.

پشتیبانی از تونل DNS (DNSTT) با پروتکل داخلی SOCKS5، SSH یا VLESS + اسکنر واقعی پورت ۵۳ (بدون پینگ ICMP).

اسکنر حرفه‌ای چندشبکه‌ای IP تمیز:

پشتیبانی از Cloudflare، Akamai (بدون نیاز به ورود دستی پورت)، Fastly، Gcore، WARP / MASQUE و لیست دلخواه (IP تکی، CIDR و بازه start-end).

حالت ملایم (Gentle Mode) ضدبلاک اپراتور، سنجش هم‌زمان پینگ، جیتر، پکت‌لاس، دست‌دهی TLS و سرعت دانلود (KB/s) همراه با خروجی TXT / CSV و اعمال یک‌لمسی.

امکانات کاربردی اندروید و ویندوز:

تب اختصاصی نمودار مصرف (نشست فعلی، روزانه، هفتگی و ماهانه)، قوانین بایپس سایت‌های ایرانی و حذف تبلیغات (AdBlock)، اشتراک‌گذاری VPN روی هات‌اسپات/LAN، و انتخاب حالت VPN / Proxy (و TUN / System Proxy در ویندوز) از بخش تنظیمات.

🇬🇧 Project Overview (English)

pnifox is a unified native Android & Windows client built with Kotlin + Jetpack Compose (Material 3) that combines multi-engine circumvention, a Gaming DNS Spy optimizer, DNS tunneling, and a multi-CDN clean IP scanner in a compact, bilingual interface.

✨ Key Features

Unified Unblock Hub (Zero-Server Default):

Defaults to MASQUE over HTTP/2 + Psiphon Chain for reliable, low-friction connectivity.

Smart Endpoint Caching saves the last working scanned IP for instant subsequent reconnects.

Supports Akamai/CDN Fronting, WireGuard over MASQUE, MHR Relay, and Tor bridges.

Live log-driven status narration, real-time Connected Exit IP, Active Network Changes summary, live upload/download speed, and multi-target HTTP 204 real delay probing.

Gaming & DNS Spy Optimizer:

DNS Spy & Hijack Guard: Probes gaming & anti-sanction resolvers simultaneously, flags poisoned/hijacked responses (10.10.34.x), and ranks clean servers.

No-Registration Private/Gaming DNS with zero extra routing latency.

Live Game Publisher Ping Catalog: Measures live TLS delay and probe loss for COD Mobile, Steam, Valorant, PUBG, Fortnite, and EA/FC.

Built-in Local DPI Desync (Zero-Server), custom gaming/Cloud panel server support, and one-tap Android Battery Optimization Bypass.

Modern Multi-Protocol Server Support:

Full support for VLESS, VMess, Trojan, Shadowsocks, WireGuard, Reality, XHTTP/SplitHTTP, WebSocket, gRPC, HTTPUpgrade, Hysteria2, TUIC v5, and AnyTLS.

Includes TLS Fragment, UDP Noise, Proxy Chaining, local SNI Spoof (127.0.0.1:40443), and a built-in Cloudflare Worker wizard.

Unified DNS Tunnel & Resolver Suite:

Consolidated protocol list (UDP, SuperDNS, FastDNS, PDoQ, DoH, DoT), DNSTT over SOCKS5/SSH/VLESS, and a Zero-ICMP Port-53 E2E scanner.

Advanced Multi-CDN Clean IP Scanner:

Supports Cloudflare, Akamai (auto-443, no manual port needed), Fastly, Gcore, WARP, and custom IPs, CIDRs, or start-end IP ranges.

Gentle ISP Mode, multi-metric ranking (latency, jitter, packet loss, TLS handshake, KB/s download speed), one-tap apply, and TXT / CSV export.

Cross-Platform Essentials:

Dedicated Traffic Stats tab, Iran bypass & AdBlock rulesets, Hotspot/LAN VPN sharing, and clean VPN/Proxy (Android) & TUN/System Proxy (Windows) controls inside Settings.
